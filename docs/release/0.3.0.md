wheel install and from a fresh sdist install: `quick start OK: (40, 40), 1120
finite pixels`. `check_dist_contents`: `distribution contents OK`. The two
skips are the GPU-only tests, which ran on the ROCm gate.

The benchmark printed during the ROCm gate — 0.0259 s batched/jitted on ROCm
against 6.7825 s looped CPU, 261.7x — is a cross-backend batch-vs-loop figure,
not a like-for-like comparison, and no test asserts on it. A QA re-run of the
same suite printed 0.0259 s against 6.7465 s (260.3x): the timing moves by a
few percent between runs while the pass count does not, which is why this row
is record-only.

## Credential note

real use of reprojax's publisher. Attestations are present and verified for
both files. The publisher binding itself has no read API and is owner-reported.
`v0.2.0` shipped with an account-scoped API token and therefore has no PEP 740
attestations; that record is unchanged.
